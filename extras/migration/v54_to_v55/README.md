# v5.4 to v5.5 CDM conversion

The *_migration.sql scripts in this folder migrate a v5.4 CDM to a v5.5 CDM.
These scripts follow the migration pattern already used in this repository and cover
the structural deltas reflected in the v5.4 and v5.5 DDLs under inst/ddl.
Please replace @cdmDatabaseSchema with your schema name.
