Changes v5.3 → v5.4

For a full description of each table and field listed here, please see the CDM v5.4 specification.

Notation:

  • a + indicates an addition to the model, either a table or field.
  • a → indicates an alteration either in naming or specification.
  • a - indicates a subtraction from the model, either a table or field.

Summary

  • 8 fields renamed.
  • 8 field definitions changed.
  • 21 fields added to existing tables, all non-required except for one (metadata_id).
  • 3 tables added: EPISODE, EPISODE_EVENT and COHORT.
  • 1 table removed: ATTRIBUTE_DEFINITION.
